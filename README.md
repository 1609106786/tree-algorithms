一个**纯前端交互式教学工具**，通过三个标签页动态演示 **B树、哈夫曼树、线索二叉树** 的构建与操作过程。

## ✨ 核心特性

### 🌳 三大模块，一键切换
通过顶部标签栏在三种树结构之间流畅切换，每个模块独立运行、互不干扰。

---

### 📊 B树构建
- 🔢 **阶数自由调节**：支持 3～7 阶 B树（即 2‑3 树到 2‑7 树），动态演示最大/最小键数约束。
- ➕ **逐步插入键值**：直观展示**节点分裂**与**关键码上提**的全过程，新分裂节点高亮显示。
- 🎭 **四种预设序列**：升序插入 / 随机序列 / 交替模式 / 密集插入，充分体现不同场景下的分裂行为。
- ✏️ **自定义输入**：支持任意整数序列（逗号或空格分隔），可自行构造测试用例。
- 📈 **实时树属性**：实时显示当前 B树的深度、键总数、节点数及阶数信息。

### 🌿 哈夫曼树
- 💡 **贪心合并动画**：每次选取森林中频率最小的两个节点合并，新内部节点高亮闪烁，逐步收缩为唯一根节点。
- 🎁 **四组预设数据**：经典示例、英语字母频率、简单演示、均匀分布，覆盖不同应用场景。
- ⌨️ **自定义字符频率**：按 `字符:频率` 格式输入（如 `a:5,b:9`），可即时生成哈夫曼树。
- 📋 **编码表自动生成**：构建完成后自动显示每个字符的哈夫曼编码、频率及编码位数。
- 0️⃣1️⃣ **树上编码标注**：最终树形图中，左/右分支分别标注 `0` / `1` 编码位。

### 🧵 线索二叉树
- 🧭 **三种遍历方式**：支持**中序、前序、后序**线索化，可随时切换，立即重绘。
- 🌲 **五种预设树形**：完全二叉树、表达式树、左偏树、右偏树、小型演示，涵盖平衡与极端情况。
- 🔗 **指针双态绘制**：实直曲线区分「孩子指针」与「线索指针」，线索指针用粉色虚线弧线连接前驱/后继。
- 🎯 **节点状态高亮**：当前访问节点橙色光晕，`pre` 前驱节点紫色虚线环绕，线索指针用红色强调最新添加。
- 📜 **遍历序列输出**：线索化完成后，直接输出对应方式的遍历序列，验证线索化的正确性。

### 🎮 全局交互特性
- ⏯️ **完整的播放控制**：首步 / 前一步 / 下一步 / 末步 / 重置 按钮，支持自动顺序播放，**播放速度四档可调**（快/中/慢/极慢）。
- ⌨️ **丰富的键盘快捷键**：
  - `←` / `→`：前后步进
  - `空格`：播放 / 暂停
  - `Home` / `End`：跳至第一步 / 最后一步
  - `R`：重置当前模块
- 📱 **移动端完美适配**：响应式布局 + 触摸滑动切换步骤，Canvas 自适应设备像素比，保证清晰度。
- 🎨 **精美的 UI 设计**：柔和渐变背景、圆角卡片、细腻阴影、主题色彩区分不同节点类型，视觉舒适。

## 🛠️ 技术栈

- **HTML5 / CSS3** – 语义化结构 + 现代化 UI 设计
- **Canvas 2D API** – 所有节点、连线、高亮均为实时矢量绘制，无任何图片资源
- **原生 JavaScript (ES6)** – 面向对象封装 `BTreeNode`、`HuffmanNode`、`ThreadedNode` 以及对应算法逻辑
- **零依赖** – 不引用任何第三方框架或库，单个 `index.html` 文件包含全部代码

## 📦 本地运行与部署

### 本地使用
1. 克隆仓库到本地：
   git clone https://github.com/1609106786/tree-algorithms.git
2. 直接用浏览器打开 `index.html` 即可。

### 部署为静态网站
项目已通过 **GitHub Pages** 部署。若你复刻（fork）后需要部署自己的版本：
1. 仓库设为 **Public**
2. 进入仓库 `Settings` → `Pages`
3. `Source` 选择 **Deploy from a branch**，分支选择 `main`，文件夹选择 `/ (root)`
4. 点击 **Save**，一分钟左右即可通过 `https://你的用户名.github.io/仓库名/` 访问

你也可以将 `index.html` 直接上传到 **Netlify**、**Vercel** 或任何静态文件托管服务。
